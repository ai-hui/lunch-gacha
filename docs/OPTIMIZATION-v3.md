## 三、P0：彻底移除「减少动效」这套逻辑（**最高优先级**）

### 用户原话
> 「不需要『减少动效』，动效就是整个程序最重要的东西，减了干嘛？越炫越好」

### 现状
上一轮为了修「动画被系统偏好吞掉」的回归，引入了：
- `index.html:880-881`：`var REDUCE_MOTION = ...matchMedia("(prefers-reduced-motion: reduce)")...`
- `index.html:461` 附近：`@media (prefers-reduced-motion: reduce){ ... }` 媒体查询
- `index.html:1528` 附近：`if(REDUCE_MOTION){ ... }` 的分支逻辑

用户不要这套东西。**不是要「收窄作用域」，是要彻底删掉。**

### 改法

**1. 删除 CSS 媒体查询块**
把 `@media (prefers-reduced-motion: reduce){ ... }` **整块删除**，包括里面的
`*{transition-duration:.01ms!important}`。系统偏好不再影响任何视觉表现。

**2. 删除 `REDUCE_MOTION` 变量及其所有引用**
- 删掉变量声明。
- 删掉所有 `if(REDUCE_MOTION){...}` 分支。
- 搜遍全文确保没有残留引用（`grep REDUCE` 应为空）。

**3. 保留「演出强度」用户设置 `S.animStyle`**
这个**要保留**，因为它是**用户主动选的**，不是系统替用户做的决定。
但要求调整：
- 三档改名为：**🎬 全开**（full）/ **⚡ 快速**（lite）/ **⏭️ 关闭**（off）。
- 默认 `"full"`（全开）。
- `lite` 仍然是「时长压缩但步骤不减」。
- 界面上要有一行说明，**明确告诉用户「本程序不理会系统的减少动效设置」**，
  避免用户以为「为什么我在系统里关了动画这里还在动」。

**4. `dur()` 函数保留**
它是 `lite` 档的时长缩放器，与系统偏好无关，保留。

### P0 验收口径
1. 全文 `grep -i "reduce" index.html` **不应再出现 `REDUCE_MOTION`**，
   也不应再有 `prefers-reduced-motion` 媒体查询块（`animStyle` 相关的字样不算）。
2. Playwright `reduced_motion="reduce"` 与默认环境**表现一致**：动画都照播，
   背景装饰动画也不被关掉。
3. `animStyle` 三档仍然工作，刷新后保持。
4. 抽签全程零 console error、零未捕获异常。

## 四、P1：新增塔罗牌抽签（**用户点名要的重点功能**）

### 用户原话
> 「再加几个动画，比如塔罗牌，让人手动选张牌然后要有真正的塔罗牌解析，
> 翻开要有塔罗牌的真实牌面和抽到什么食物」

### 需求拆解（这是本轮最重要的功能，做不好等于没做）
1. **手动选牌**：不是随机翻，而是**用户点选**。
2. **真实牌面**：翻开要显示**真正的塔罗牌牌面**（78 张标准塔罗牌体系）。
3. **真正的塔罗牌解析**：显示该牌的**正位/逆位牌意**（真实的塔罗牌义，不是编的）。
4. **牌面上要同时显示抽到什么食物**：即「这张牌 + 这个食物」的结合。

### 实现方案

**牌库**：完整的 78 张标准塔罗牌。

- **大阿卡纳 22 张**（0–21）：愚者、魔术师、女祭司、皇后、教皇、恋人、战车、力量、
  隐士、命运之轮、正义、吊人、死神、节制、恶魔、高塔、星星、月亮、太阳、
  审判、世界。
  - 每张要有：**中文名**、**英文名**、**罗马数字**、**牌面 SVG 图案**、**正位牌意**、**逆位牌意**。
- **小阿卡纳 56 张**：权杖/圣杯/宝剑/星币 四花色 × (数字 1–10 + 侍从/骑士/皇后/国王)。
  - 每张要有：**中文名**（如「权杖三」「圣杯骑士」）、**正位牌意**、**逆位牌意**。
  - 牌面图案：用**该花色的符号 SVG**（权杖=权杖/树枝、圣杯=圣杯、宝剑=剑、星币=星币）
    + 数字/宫廷标识。**不要**给 56 张小牌各画一幅不同的复杂插画——
    用「花色符号 + 数字牌阵」的方式呈现即可（这本身就是很多塔罗牌的真实画法）。

**牌面 SVG**：必须用**内联 SVG** 画，不能用 emoji 凑数，不能引用外部图片。
- 大阿卡纳每张给一个**有辨识度的简化图标**（例：太阳=圆+光芒、月亮=月牙+星星、
  高塔=塔身+闪电、星星=五角星+光晕、恶魔=角+倒三角、命运之轮=圆轮+辐条…）。
- 小阿卡纳用**花色符号 SVG** 复用。

**交互流程（严格按此顺序）**：
1. 抽到食物和稀有度后，进入塔罗牌环节。
2. 舞台上出现 **3 张背面朝上的塔罗牌**（微微扇形排开 + 悬浮呼吸动画 + 星光粒子）。
3. **用户手动点击其中一张**（要有 hover 高亮 + cursor:pointer + 牌身抬起预兆）。
   - 倒计时**不强制**（不自动替你选），但要有**明确的操作提示**（例如「👆 点选一张牌」）。
   - **必须有一个兜底**：若用户 20 秒未选，自动随机选一张（不能让流程卡死）。
4. 被选中的牌 **3D 翻转**（`rotateY` 180°，`transform-style:preserve-3d`），
   翻面后显示：
   - **上半部分**：该牌的**真实牌面 SVG**（大阿卡纳的专属图案 / 小牌的花色符号）+ 罗马数字或花色数字
   - **下半部分**：**抽到的食物名 + 稀有度**（如「🍜 沙县」+「SSR」）
5. 翻开后展示**该牌的牌意解析**：正位一段、逆位一段（每张牌都要有真实牌意）。
   - 同时给一句**结合食物的解读**（把牌意和今天吃的食物串起来，写得有趣一点）。
6. 牌面要有**光效**：稀有度越高，边框流光/粒子越强（复用现有的 `burst()` 与金色流光样式）。

**数据结构建议**（在 script 里定义一个 `TAROT` 数组，便于维护）：
```js
var TAROT = {
  major: [ {n:0, name:"愚者", en:"The Fool", svg:"<svg...>", up:"...", down:"..."}, ... ],
  suits: [ {key:"wands", name:"权杖", symbol:"<svg...>"}, ... ],
  minor: [ {suit:"wands", num:1, name:"权杖一", up:"...", down:"..."}, ... ]
};
```
小牌牌面由 `suits` 的 symbol + `num` 组合生成，不必为 56 张各写 SVG。

**牌意质量要求（重要）**：
- 必须是**真实的标准塔罗牌义**，不能编。
- 大阿卡纳每张的正逆位牌意要符合通行的 Rider–Waite 体系。
- 小阿卡纳按花色+数字给出通行的关键词与牌意。
- 牌意文字**简短有力**，每条 15~40 字，不要写成百科长文。

**食物结合解读**：每张牌配一句结合食物的俏皮话（可用模板 + 牌意关键词生成，
但要保证读起来通顺，不要明显的机械拼接）。

### P1 验收口径
1. `ANIM_LIST` 里有塔罗牌（key 建议 `tarot`），动画选择器里有对应按钮。
2. 点「抽下一天」后，**出现 3 张背面朝上的牌**，且**不自动翻开**（等用户点）。
3. 点击其中一张 → 该牌翻转 → 显示**真实牌面 SVG**（断言 DOM 里有 `<svg>`，
   且 SVG 里有非零尺寸的路径/形状，不是空 svg，也不是 emoji 文本）。
4. 翻开后的面板里**同时出现**：食物名、稀有度、该牌的牌名、**正位牌意**、**逆位牌意**。
5. **牌库完整性**：断言 78 张牌全部存在（`TAROT.major.length === 22`，
   小牌 56 张），且每张都有非空的 `up` 和 `down` 文本。
6. 20 秒不选 → 自动选一张，流程不卡死（可把超时临时改短来测）。
7. 塔罗牌抽完后，结果**正常落盘到菜单**（食物 + 稀有度正确），零 console error。
8. `prefers-reduced-motion` 不影响塔罗牌翻转（因为压根不读这个偏好了）。

## 五、P2：再补几套炫酷动画（用户说「再加几个动画」）

在塔罗牌之外，**再新增 2~3 套**，风格要和已有的（魔法阵 / CSGO / 老虎机 / 卡牌）明显不同，
越炫越好：

- **🔥 地狱烈焰召唤（`inferno`）**：底部喷发火焰粒子上升 → 逐渐聚成结果文字 → 爆燃。
  可复用 `burst()` 但要用**向上喷发**的粒子参数（负的重力/上升速度）。
- **🌌 星象召唤（`astro`）**：Canvas 画一个旋转的星座连线网络（随机点 + 连线），
  某个点突然高亮放大 → 变成结果。
- **💎 宝石切面爆裂（`gem`）**：多边形晶体用 CSS `clip-path` 做出切面，
  从中心裂开 → 碎片飞散 → 露出结果。

要求：
- 每套都要有自己的**视觉主题色**，不要四套都紫粉。
- 都要有**音效**（复用 `tone()` / `noise()` / `sfxTick()`，不要新增音频文件）。
- 都要**播完能清理干净**（不留常驻合成层、不留残余 DOM）。
- 都要**异常安全**：内部抛错不阻断抽签。
- 「随机」轮换池要能轮到新动画（`ANIM_LIST` 加进去后，
  `pickAnim()` 的权重封顶值要相应调整，**保证每套都有保底权重**，
  别让最久没出现的那套几乎必出）。**改完要同步更新 `#animStat` 的说明文案**。
